Graph-based retrieval-augmented generation with agentic reasoning.

## Installation

```bash
uv pip install agentic-graphrag
```

Usage:

```python
import agrag
```

## Development

Requires [uv](https://docs.astral.sh/uv/).

```bash
git clone git@github.com:ontogr/agentic-graphrag.git
cd agentic-graphrag
make sync
```
