# `agrag.embedding.base` \{#agrag-embedding-base}

The Embedder and EmbeddingCache protocols.

**Classes:**

- [**Embedder**](Embedder.md) – A component that turns text into dense embedding vectors.
- [**EmbeddingCache**](EmbeddingCache.md) – A content-addressed cache for embedding vectors.
- [**NullEmbeddingCache**](NullEmbeddingCache.md) – A cache that never stores anything. The default when none is injected.
