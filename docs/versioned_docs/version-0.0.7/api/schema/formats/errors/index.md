# `agrag.schema.formats.errors` \{#agrag-schema-formats-errors}

Errors raised by schema format importers.

**Classes:**

- [**SchemaFormatError**](SchemaFormatError.md) – An input document cannot be imported as a supported schema format.
- [**SchemaFormatMissingExtraError**](SchemaFormatMissingExtraError.md) – An optional package required by a schema format is not installed.
