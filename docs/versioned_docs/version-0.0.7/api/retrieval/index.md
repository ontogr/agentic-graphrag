# `agrag.retrieval` \{#agrag-retrieval}

Retrieval configuration, filters and shared search helpers.

**Modules:**

- [**chunking**](chunking/index.md) – Turns graph node values into Chunk models for retrieval.
- [**filters**](filters/index.md) – Constraints applied across every retrieval method in one call.
- [**methods**](methods/index.md) – Low-level search method helpers shared by evidence search and ingestion.
- [**settings**](settings/index.md) – Env-backed configuration for evidence search and rerank.
- [**tracing**](tracing/index.md) – Span helpers shared by the retrieval spans.

**Classes:**

- [**RetrievalSettings**](settings/RetrievalSettings.md) – Configuration for evidence search fusion and rerank.
- [**SearchFilters**](filters/SearchFilters.md) – Constraints applied across every retrieval method in one call.
