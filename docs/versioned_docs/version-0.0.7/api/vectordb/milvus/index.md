# `agrag.vectordb.milvus` \{#agrag-vectordb-milvus}

Milvus dense and native BM25 indexes for external vector placement.

**Classes:**

- [**MilvusSettings**](MilvusSettings.md) – Milvus or Zilliz Cloud connection and collection namespace.
- [**MilvusVectorStore**](MilvusVectorStore.md) – Store UUID-keyed vectors with server-generated BM25 sparse vectors.
