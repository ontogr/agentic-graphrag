# `agrag.embedding.errors` \{#agrag-embedding-errors}

Errors that the embedding layer raises.

**Classes:**

- [**EmbeddingDimensionMismatchError**](EmbeddingDimensionMismatchError.md) – A stored collection or index expects a different embedding dimension.
- [**EmbeddingError**](EmbeddingError.md) – The base class for every embedding error.
- [**EmbeddingMissingExtraError**](EmbeddingMissingExtraError.md) – An embedder exists, but its package extra is not installed.
