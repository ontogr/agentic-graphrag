# `agrag.candidates.review` \{#agrag-candidates-review}

List and change the review state of candidate groups.

**Functions:**

- [**approve_candidates**](approve_candidates.md) – Approve resolvable candidates and plan a deterministic schema patch.
- [**list_candidates**](list_candidates.md) – List candidate groups, ordered and paged by aggregate sightings.
- [**move_candidates**](move_candidates.md) – Move candidate groups whose current states allow `to_state`.
- [**prune_candidates**](prune_candidates.md) – Count or delete groups matching the selected prune criteria.
- [**reject_candidates**](reject_candidates.md) – Reject selected candidate groups and retain them as suppression records.
