# Introduction

Agentic GraphRAG is an open source Python framework that connects your documents, agent activity, and decisions in one graph. Your agents can find evidence, continue work across sessions, and revisit decisions when their sources change.

## What it keeps in the graph

Agentic GraphRAG keeps three connected kinds of memory in one Neo4j graph.

- Knowledge: your documents, with their sections, chunks, entities, relations, and community summaries.
- Working memory: named tasks, an ordered log of what an agent said, called, and received, and the steps of each task.
- Decisions: conclusions with their rationale and the passages, events, or other decisions they rely on.

Add your documents and they become a knowledge graph shaped by your own schema. Agents search the graph, read the exact passage behind each result, and cite it. They record decisions that point to the passages they rely on. A later session picks a task up where it stopped, and a decision is flagged for review when a document behind it changes.

For example, a contract-review agent records a recommendation with passages from a contract and a policy. A later session retrieves the task and its decision. When the policy changes, the decision is flagged for review against the new text.

## Three ways to use it

- The Python library. Use `Graph` to add documents, the functions in `agrag.evidence` to search and cite, and `agrag.memory` to record tasks and decisions.
- The built-in agent. `build_agent` returns a task-scoped agent that searches your documents, records its work, and answers with numbered sources.
- The MCP server. `agrag-mcp` gives any MCP client tools to search, read, cite, and keep task and decision memory.

## How it works

```mermaid
flowchart LR
    docs[Your documents] --> ingest[Ingest]
    ingest --> graph[(Neo4j graph)]
    question[Your question] --> agent[Agent or MCP client]
    agent -->|search and read| graph
    agent -->|tasks and decisions| graph
    agent --> answer[Cited answer]
```

*Ingestion builds the graph. The agent or MCP client reads it and records tasks and decisions in it.*

1. You add documents. Agentic GraphRAG loads them, splits them into chunks, and extracts entities and relations.
2. Agentic GraphRAG resolves duplicate mentions and writes the graph and its indexes to Neo4j.
3. You ask a question. The agent discovers and fetches evidence from the graph.
4. The agent checks its citations against the fetched evidence and writes an answer with numbered sources.
5. The agent records its messages, tool results, and decisions under a named task.

## Who it is for

Use Agentic GraphRAG if you:

- build agents that answer from documents that you own.
- need answers that cite their sources.
- want agents that continue a task across sessions.
- want to define your own entity and relation types.

## What you need

- Python 3.11 or newer.
- A Neo4j database, version 5.23 or newer.
- An OpenAI-compatible LLM endpoint for the built-in agent. Embeddings and local extraction run on your machine.
