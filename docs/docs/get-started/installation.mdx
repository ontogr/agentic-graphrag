# Installation

This page shows how to install `agrag` with the extras that you need.

## Requirements

- Python 3.11 or newer.
- [uv](https://docs.astral.sh/uv/) or pip.
- A Neo4j database, version 5.23 or newer, to store the graph. The [Quickstart](/get-started/quickstart) shows how to get one for free.

## Install the package

Create a virtual environment. Then install the package:

```bash
uv venv
uv pip install agentic-graphrag
```

The base install includes the loaders, the chunkers, and the data models. Storage, embeddings, extraction, and the agent are extras.

Check the install:

```python
import agrag

print(agrag.__version__)
```

## Choose your extras

Add an extra in square brackets, for example `agentic-graphrag[neo4j,extract]`.

| Extra | Adds |
| --- | --- |
| `neo4j` | The Neo4j graph store and its native vector index |
| `embed-local` | Sentence Transformers embeddings that run on your machine |
| `extract` | GLiNER 2.5 extraction that runs on your machine |
| `llm` | BAML extraction and match verification with an LLM |
| `agents` | The LangGraph runtime for the question-answering agent |
| `docling` | PDF, Word, PowerPoint, image, and XML parsing, and layout-aware chunking |
| `qdrant` | The Qdrant vector store and BM25 sparse embeddings |
| `weaviate` | The Weaviate vector store |
| `milvus` | The Milvus and Zilliz vector store |
| `observability` | The OpenTelemetry SDK and OTLP exporter |
| `community` | Leiden community detection |
| `eval` | The DeepEval and AgentEvals metrics in `agrag.eval` |
| `chunk-semantic` | The semantic chunker |
| `chunk-neural` | The neural chunker |
| `chunk-code` | The code chunker |

Pick the extras for your goal:

| Goal | Extras |
| --- | --- |
| Build a first graph (the [Quickstart](/get-started/quickstart)) | `neo4j,extract,embed-local` |
| Also ask questions with the agent | `neo4j,extract,embed-local,agents` |
| Read PDF and Office files | Add `docling` |
| Extract with an LLM instead of a local model | `neo4j,llm,embed-local` |
| Search with a dedicated vector store | Add `qdrant`, `weaviate`, or `milvus` |
| Record traces | Add `observability` |

## Save disk space with CPU-only PyTorch

The `extract` and `embed-local` extras install PyTorch. On Linux, the default PyTorch wheel brings several gigabytes of NVIDIA CUDA libraries. If your machine has no GPU, install the CPU build first:

```bash
uv venv
uv pip install torch --index-url https://download.pytorch.org/whl/cpu
uv pip install "agentic-graphrag[neo4j,extract,embed-local]"
```

The second command keeps the CPU build. The environment for these three extras is about 1.1 GB.
