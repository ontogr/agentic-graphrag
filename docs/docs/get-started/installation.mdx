# Installation

This page shows how to install `agrag` and choose the extras that you need.

## Requirements

- Python 3.11 or newer.
- [uv](https://docs.astral.sh/uv/) or pip.
- A Neo4j database, version 5.23 or newer, to store the graph. The [Quickstart](/get-started/quickstart) shows how to get one for free.

## Install the package

To use `agrag`, install `agentic-graphrag` from your Python package manager.

With pip:

```bash
pip install agentic-graphrag
```

With [uv](https://docs.astral.sh/uv/):

```bash
uv add agentic-graphrag
```

To install uv, see the [installation docs](https://docs.astral.sh/uv/getting-started/installation/).

Check the install:

```python
import agrag

print(agrag.__version__)
```

## What the base install includes

The base install has the parts of `agrag` that need no database, no model runtime, and no LLM client:

- The data models, such as the graph schema and the search result.
- Loaders for files, directories, and raw text, including Markdown, HTML, and CSV.
- The built-in chunkers: recursive, sentence, token, heading, parent-child, and turn-window.
- The OpenTelemetry API calls that trace each step. Without the `observability` extra, these calls do nothing.

To build and search a graph, you also need a graph store, an extractor, and an embedder. Each one comes as an extra.

## Install extras

Different parts of `agrag` need different packages. The base install leaves these packages out, so that you install only what you use. Each group of packages is an extra.

Add the extras in square brackets, separated by commas:

```bash
pip install "agentic-graphrag[neo4j,extract,embed-local]"
```

```bash
uv add "agentic-graphrag[neo4j,extract,embed-local]"
```

If an extra is missing, `agrag` raises an error that names the extra to install.

### Available extras

| Extra | Adds |
| --- | --- |
| `neo4j` | The Neo4j graph store and its native vector index |
| `embed-local` | Sentence Transformers embeddings that run on your machine |
| `extract` | GLiNER 2.5 extraction that runs on your machine |
| `llm` | BAML extraction and match verification with an LLM |
| `agents` | The LangGraph runtime for the question-answering agent |
| `docling` | PDF, Word, PowerPoint, image, and XML parsing, and layout-aware chunking |
| `qdrant` | The Qdrant vector store and BM25 sparse embeddings |
| `weaviate` | The Weaviate vector store |
| `milvus` | The Milvus and Zilliz vector store |
| `observability` | The OpenTelemetry SDK and OTLP exporter |
| `community` | Leiden community detection |
| `eval` | The DeepEval and AgentEvals metrics in `agrag.eval` |
| `chunk-semantic` | The semantic chunker |
| `chunk-neural` | The neural chunker |
| `chunk-code` | The code chunker |

### Extras by goal

| Goal | Extras |
| --- | --- |
| Build a first graph (the [Quickstart](/get-started/quickstart)) | `neo4j,extract,embed-local` |
| Also ask questions with the agent | `neo4j,extract,embed-local,agents` |
| Read PDF and Office files | Add `docling` |
| Extract with an LLM instead of a local model | `neo4j,llm,embed-local` |
| Search with a dedicated vector store | Add `qdrant`, `weaviate`, or `milvus` |
| Find communities of related entities | Add `community` |
| Record traces | Add `observability` |
| Measure answer quality | Add `eval` |

## Choose a PyTorch build

The `embed-local`, `extract`, `docling`, and `chunk-neural` extras depend on PyTorch. To choose the PyTorch build, for example a CPU-only build on Linux, use one of these methods.

With `uv pip`, add `--torch-backend=auto`. uv looks for a GPU driver. It installs the build that matches the driver, or the CPU build when it finds no GPU.

```bash
uv pip install "agentic-graphrag[neo4j,extract,embed-local]" --torch-backend=auto
```

To always install the CPU build, use `--torch-backend=cpu`. This flag is a uv preview feature, and it works with `uv pip` only.

With `uv add`, list `torch` as a direct dependency in your `pyproject.toml`, and point it at the CPU index. uv applies an index to direct dependencies only.

```toml
[project]
dependencies = ["torch", "agentic-graphrag[neo4j,extract,embed-local]"]

[tool.uv.sources]
torch = { index = "pytorch-cpu" }

[[tool.uv.index]]
name = "pytorch-cpu"
url = "https://download.pytorch.org/whl/cpu"
explicit = true
```

With pip, install the CPU build first. The second command keeps it.

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install "agentic-graphrag[neo4j,extract,embed-local]"
```

For other builds, such as a specific CUDA version, see the [PyTorch install page](https://pytorch.org/get-started/locally/).
