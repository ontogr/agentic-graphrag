# `agrag.loaders.records` \{#agrag-loaders-records}

Record readers: CSV, TSV, JSON Lines, and JSON.

**Classes:**

- [**CsvLoader**](CsvLoader.md) – Reads CSV and TSV files as one document per row.
- [**JsonLoader**](JsonLoader.md) – Reads JSON files, disambiguating arrays from objects.
- [**JsonlLoader**](JsonlLoader.md) – Reads JSON Lines files as one document per line.
