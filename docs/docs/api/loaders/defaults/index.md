# `agrag.loaders.defaults` \{#agrag-loaders-defaults}

The loaders that the corpus registry holds by default.

**Functions:**

- [**default_registry**](default_registry.md) – Return a new registry with every default loader registered.
- [**register_default_loaders**](register_default_loaders.md) – Register every default loader on a registry.
