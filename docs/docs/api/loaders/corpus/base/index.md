# `agrag.loaders.corpus.base` \{#agrag-loaders-corpus-base}

The Loader interface: reads one source and yields Document objects.

**Classes:**

- [**Loader**](Loader.md) – Reads one source and yields Document objects.
- [**ProseLoader**](ProseLoader.md) – A loader that makes one Document per source.
- [**RecordLoader**](RecordLoader.md) – A loader that makes one Document per record in a source.
