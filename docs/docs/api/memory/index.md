# `agrag.memory` \{#agrag-memory}

Durable task and decision memory for one project.

**Modules:**

- [**decisions**](decisions/index.md) – Evidence-linked decisions scoped to one project.
- [**tasks**](tasks/index.md) – Durable task state with raw events and steps, scoped to one project.

**Classes:**

- [**DecisionMemory**](decisions/DecisionMemory.md) – Write and search durable decisions for one configured project.
- [**TaskMemory**](tasks/TaskMemory.md) – Durable task state for one project, written on behalf of one agent.
