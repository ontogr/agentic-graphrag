# `agrag.candidates.patch` \{#agrag-candidates-patch}

Plan and serialize deterministic candidate schema patches.

**Functions:**

- [**candidate_patch**](candidate_patch.md) – Build a patch from approved candidate records in the graph.
- [**declares_property**](declares_property.md) – Check whether an entity type directly declares a property.
- [**endpoint_type**](endpoint_type.md) – Select the most specific declared type among an entity's labels.
- [**plan_patch**](plan_patch.md) – Plan sorted schema additions and evidence from candidate records.
- [**read_patch**](read_patch.md) – Read a JSON file and validate it as a schema patch.
- [**write_patch**](write_patch.md) – Write the patch as indented JSON, refusing replacement by default.
