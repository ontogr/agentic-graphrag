# `agrag.schema.errors` \{#agrag-schema-errors}

Errors that the schema loader raises.

**Classes:**

- [**Issues**](Issues.md) – Collects issues so that one load reports every problem.
- [**SchemaError**](SchemaError.md) – The base class for every schema-loader error.
- [**SchemaIssue**](SchemaIssue.md) – One problem found in a schema source.
- [**SchemaLoadError**](SchemaLoadError.md) – A schema source is invalid.
