# `agrag.schema.formats.owl` \{#agrag-schema-formats-owl}

Import the supported OWL and RDFS Turtle subset.

**Functions:**

- [**load_owl**](load_owl.md) – Load the supported OWL/RDFS subset from a local UTF-8 Turtle file.
- [**loads_owl**](loads_owl.md) – Load the supported OWL/RDFS subset from Turtle text.
