# `agrag.schema.formats.dispatch` \{#agrag-schema-formats-dispatch}

Hooks that let `load_schema` read Pydantic classes and Turtle files.

**Functions:**

- [**is_model_source**](is_model_source.md) – Return whether `source` is a Pydantic class or a list of them.
- [**read_models**](read_models.md) – Read a schema from a Pydantic class or a list of classes.
- [**read_owl_file**](read_owl_file.md) – Read Turtle and return its validated canonical schema data.
