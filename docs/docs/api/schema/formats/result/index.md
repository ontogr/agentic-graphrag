# `agrag.schema.formats.result` \{#agrag-schema-formats-result}

The value that every schema import returns.

**Classes:**

- [**FormatWarning**](FormatWarning.md) – One thing an import dropped, changed or could not map.
- [**ImportResult**](ImportResult.md) – A schema read from another format, with everything the read lost.
