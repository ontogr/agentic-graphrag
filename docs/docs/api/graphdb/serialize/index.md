# `agrag.graphdb.serialize` \{#agrag-graphdb-serialize}

Convert graph records to driver parameters and graph node rows to models.

**Functions:**

- [**node_params**](node_params.md) – Build the `$records` entry for a node upsert.
- [**parse_entity_node**](parse_entity_node.md) – Parse one stored entity's property dict into an Entity.
- [**relation_params**](relation_params.md) – Build the `$records` entry for a relationship upsert.
