# `agrag.history` \{#agrag-history}

Public conversation history APIs.

**Modules:**

- [**retention**](retention/index.md) – Project-scoped redaction and task deletion operations.
- [**tasks**](tasks/index.md) – Conversation history with raw events and steps, scoped to one project.

**Classes:**

- [**ConversationHistory**](tasks/ConversationHistory.md) – Durable task state for one project, written on behalf of one agent.
- [**HistoryRetention**](retention/HistoryRetention.md) – Apply retention actions to conversation history in one project.
