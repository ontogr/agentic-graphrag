# `agrag.agents.middleware` \{#agrag-agents-middleware}

Middleware for composing configured chat models.

**Classes:**

- [**RoundRobinModelMiddleware**](RoundRobinModelMiddleware.md) – Rotate model requests across configured clients.
- [**TaskEventMiddleware**](TaskEventMiddleware.md) – Persist assistant messages as the model produces them.
