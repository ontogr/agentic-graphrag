# `agrag.vectordb.errors` \{#agrag-vectordb-errors}

Errors exposed by external vector indexes.

**Classes:**

- [**CollectionMismatchError**](CollectionMismatchError.md) – An existing collection has incompatible dimensions or distance.
- [**VectorPlacementError**](VectorPlacementError.md) – The requested vector placement disagrees with the graph's recorded placement.
- [**VectorStoreError**](VectorStoreError.md) – An external vector index operation failed.
- [**VectorStoreMissingExtraError**](VectorStoreMissingExtraError.md) – The selected vector store's optional client is not installed.
