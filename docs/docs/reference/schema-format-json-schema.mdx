# JSON Schema export

`to_json_schema(schema)` writes a JSON Schema (draft 2020-12) that checks the output of an extraction run for one schema. Use it as the response schema for an LLM call that returns structured output, or to check extraction results with a JSON Schema validator.

```python notest
import json

from agrag.schema import load_schema
from agrag.schema.formats import to_json_schema

schema = load_schema(["Person", "Company", "Person-WORKS_FOR->Company"])
print(json.dumps(to_json_schema(schema), indent=2))
```

## What the schema checks

The checked document has two arrays.

- `entities`: each item has `label`, `text` and `properties`. `label` must be a type of the schema. `properties` holds the declared properties of that type only.
- `relations`: each item has `type`, `source`, `target`, `source_label` and `target_label`. The two labels must match a pattern of the relation. A pattern that names a parent type also accepts its child types. A symmetric relation also accepts the reverse direction.

## Mapping

| Schema element | JSON Schema |
| --- | --- |
| Schema name | `title` |
| Schema name and version | `$id`, as `urn:agrag:schema:<name>:<version>` |
| Entity type | A definition in `$defs` with the type `object` |
| Entity description | `description` |
| Property type `string`, `integer`, `float`, `boolean` | `type` is `string`, `integer`, `number`, `boolean` |
| Property type `date` | `type: string` with `format: date` |
| Property `required` | `required` list of the properties object |
| Property `enum` | `enum`, with values of the property type |
| Property description | `description` |
| Relation type | A definition in `$defs` with the type `object` |
| Relation patterns | `anyOf`, one entry for each source label |

## What the schema does not check

JSON Schema checks one document. It cannot count edges across a document, so these three items appear as `x-agrag-*` annotations. A validator ignores them.

| Schema element | Annotation |
| --- | --- |
| Entity parents | `x-agrag-parents` |
| Relation `max_per_source` | `x-agrag-max-per-source` |
| Relation `max_per_target` | `x-agrag-max-per-target` |
| Relation `symmetric` | `x-agrag-symmetric` |

This page covers export only. You cannot load a schema from JSON Schema.
