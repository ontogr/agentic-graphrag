# History and decisions data model

This page lists the models that `ConversationHistory`, `DecisionTraces`, and `HistoryRetention` return. The models are defined in `agrag/common/data_models/task.py`, `decision.py`, `write_result.py`, and `retention.py`. The classes are in `agrag/history/` and `agrag/decisions.py`. For the concepts behind these fields, see [Conversation history and decisions](../concepts/conversation-history-and-decisions.mdx).

## Tasks and events

### Task

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | `UUID` | Derived from the project id and the task name. |
| `project_id` | `str` | The project that owns the task. |
| `name` | `str` | The task name, unique within the project. |
| `goal` | `str` | The goal given when the task was created. |
| `status` | `TaskStatus` | The lifecycle state. |
| `event_seq` | `int` | The sequence number of the last event, or 0. |
| `author` | `str` | The agent that created the task. |
| `created_at` | `datetime` | When the task was created. |

### Event

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `id` | `UUID` | none | Derived from the task id and the sequence number. |
| `task_id` | `UUID` | none | The task the event belongs to. |
| `seq` | `int` | none | Position in the task, from 1 with no gaps. |
| `kind` | `EventKind` | none | The kind of event. |
| `role` | `str \| None` | none | The speaker role of a message, or `None`. |
| `name` | `str \| None` | none | The tool or source name for a tool event, or `None`. |
| `payload` | `str` | none | The stored text. Cut to 32,000 characters when `truncated` is `True`. Replaced by `[REDACTED]` after a redaction. |
| `payload_sha256` | `str` | none | SHA-256 of the full text, encoded as UTF-8, before any cut. |
| `truncated` | `bool` | none | Whether the stored payload is shorter than the full text. |
| `author` | `str` | none | The agent that recorded the event. |
| `at` | `datetime` | none | When the event was recorded. |
| `redacted_at` | `datetime \| None` | `None` | When the payload was redacted. |

### Step

| Field | Type | Default | Meaning |

| `result_event_seq` | `int \| None` | none | The sequence number of the result event. |

| `result_validity` | `StepResultValidity` | `unknown` | Whether a completed result can be reused. |

### StepPage

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |

### TaskView

The bounded resume view. It never includes event bodies.

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `task_name` | `str` | none | The task name. |
| `goal` | `str` | none | The task goal. |
| `status` | `TaskStatus` | none | The lifecycle state. |
| `last_event_seq` | `int` | none | The sequence number of the last event, or 0. |
| `steps` | `dict[StepState, list[StepSummary]]` | none | Shown steps grouped by state. Every state is a key. |
| `step_counts` | `dict[StepState, int]` | none | Steps in each state, including hidden steps. Every state is a key. |
| `steps_truncated` | `bool` | none | Whether some steps are hidden. |
| `decisions` | `list[Decision]` | `[]` | Active decisions, newest first. |
| `decision_count` | `int` | `0` | The number of active decisions, including hidden ones. |
| `decisions_truncated` | `bool` | `False` | Whether some active decisions are hidden. |
| `review_decisions` | `list[Decision]` | `[]` | Active decisions that need review. |
| `conflicts` | `list[ConflictGroup]` | `[]` | Conflicting choices that include this task. |
| `conflicts_truncated` | `bool` | `False` | Whether some conflicts are hidden. |

| `EventLookup` | `found: bool`, `event: Event \| None` | The result of `fetch_event`. |

## Decisions

### Decision

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `id` | `UUID` | none | Derived from the task id, the choice key, and the revision. |
| `task_id` | `UUID` | none | The task the decision belongs to. |
| `task_name` | `str` | none | The name of that task. |
| `choice_key` | `str` | none | The choice inside the task that the decision settles. |
| `revision` | `int` | none | `1` for the first decision of a choice, then one more for each supersession. |
| `conclusion` | `str` | none | The conclusion. Never changed after recording. |
| `rationale` | `str` | none | The stated reasoning. |
| `assumptions` | `list[str]` | none | The assumptions the decision relies on. |
| `open_questions` | `list[str]` | none | The questions left open. |
| `author` | `str` | none | The agent that recorded the decision. |
| `status` | `DecisionStatus` | none | The lifecycle state. |
| `review_state` | `ReviewState` | none | Whether the supports still hold. |
| `review_reason` | `ReviewReason \| None` | `None` | Why the decision needs review. |
| `rejection_reason` | `str \| None` | `None` | The reason given when the decision was rejected. |
| `rejected_by` | `str \| None` | `None` | Who rejected the decision. |
| `created_at` | `datetime` | none | When the decision was recorded. |
| `supports` | `list[Support]` | `[]` | The stored supports, in the order given. |

### Supports

A stored support is one of three models. The `kind` field selects the model.

#### DocumentSupport

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `kind` | `"document"` | none | Always `document`. |
| `evidence_id` | `str` | none | The evidence id the caller cited. |
| `document_key` | `str` | none | The stable key of the cited document. |
| `document_node_id` | `UUID` | none | The id of the Document node. |
| `content_hash_prefix` | `str` | none | The first 16 hex characters of the cited version. |
| `content_hash` | `str` | none | The full content hash of the cited version. |
| `reference_kind` | `EvidenceKind` | none | Whether the id names a span or a chunk. |
| `char_start` | `int \| None` | `None` | Start offset of a span, or `None` for a chunk. |
| `char_end` | `int \| None` | `None` | End offset of a span, or `None` for a chunk. |
| `chunk_id` | `UUID \| None` | `None` | The chunk id of a chunk reference, or `None` for a span. |
| `recorded_activation_seq` | `int \| None` | `None` | The document's activation sequence when the decision was recorded. |
| `current` | `bool` | `True` | Whether the support is the current one. |
| `reviewed_by` | `str \| None` | `None` | Who reviewed the support. |
| `reviewed_at` | `datetime \| None` | `None` | When the support was reviewed. |
| `review_explanation` | `str \| None` | `None` | The explanation given during review. |

#### EventSupport

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `kind` | `"event"` | none | Always `event`. |
| `event_id` | `UUID` | none | The id of the event node. |
| `task_name` | `str` | none | The task that holds the event. |
| `seq` | `int` | none | The sequence number of the event in that task. |
| `current`, `reviewed_by`, `reviewed_at`, `review_explanation` | as in DocumentSupport | `True`, `None`, `None`, `None` | Review fields. |

#### DecisionSupport

| Field | Type | Default | Meaning |
| --- | --- | --- | --- |
| `kind` | `"decision"` | none | Always `decision`. |
| `decision_id` | `UUID` | none | The id of the decision depended on. |
| `current`, `reviewed_by`, `reviewed_at`, `review_explanation` | as in DocumentSupport | `True`, `None`, `None`, `None` | Review fields. |

## Methods, defaults, and limits

Each method clamps its page size to the maximum shown.

| Method | Parameter | Default | Limit |
| --- | --- | --- | --- |
| `ConversationHistory.list_events` | `after_seq`, `limit` | `0`, `50` | `limit` is 1 to 200. |
| `ConversationHistory.list_steps` | `after_name`, `limit` | `None`, `50` | `limit` is 1 to 200. |
| `ConversationHistory.record_event` | `payload` | none | At most 32,000 characters are stored. Longer text is cut. |
| `ConversationHistory.get_task` | none | none | Shows at most 50 steps, 20 active decisions, 20 review decisions, and 10 conflict groups. |
| `DecisionTraces.record_decision` | `supports` | none | At least 1 support and at most 20. |
| `DecisionTraces.supersede_decision` | `explanation` | none | Must not be blank. |
| `DecisionTraces.reaffirm_decision` | `explanation` | `"Reaffirmed after review."` | Stored with the review. |
| `DecisionTraces.list_decisions` | `include_history` | `True` | At most 20 decisions per call. |
| `DecisionTraces.list_decisions_for_review` | `task_name`, `limit` | `None`, `20` | At most 20 decisions per call. |
| `DecisionTraces.search_decisions` | `task_name`, `limit` | `None`, `20` | At most 100 results. |
| `DecisionTraces.list_support_history` | `after_ordinal`, `limit` | `-1`, `20` | At most 100 per call. |
| `DecisionTraces.continue_decision_review` | `limit` | `100` | At most 100 queued decisions per call. |
| `DecisionTraces.list_conflicts` | none | none | At most 50 groups, with at most 50 decisions shown per group. |
| `HistoryRetention.delete_task` | `include_decisions` | `True` | none |
| All writes | `request_id` | `None` | 1 to 64 characters when set. |

## Enums and states

Each table lists one enum or one state field. A value is the string stored and returned.

| Enum | Value | Meaning |
| --- | --- | --- |

| `TaskStatus` | `done` | Defined in the model. No method in this version sets it. |
| `EventKind` | `message` | A message from a speaker. Set `role` to name the speaker. |
| `EventKind` | `tool_call` | A call to a tool. Set `name` to the tool. |
| `EventKind` | `tool_result` | The result of a tool call. Set `name` to the tool. |

| `StepState` | `not_started` | The step is planned and has not begun. |
| `StepState` | `in_progress` | The step has begun, and no outcome is recorded yet. |
| `StepState` | `completed` | The step finished. Resume does not rerun it. |
| `StepState` | `failed` | The step finished with a failure. Resume reruns it. |
| `StepState` | `unknown` | The outcome is not known, for example after an interrupted run. Resume reruns it. |
| `StepKind` | `read` | A step that reads sources. |
| `StepKind` | `analysis` | A step that analyzes gathered material. |
| `StepKind` | `other` | Any other step. This is the default. |
| `StepResultBasis` | `independent` | The result does not depend on evidence. |

| Enum | Value | Meaning |
| --- | --- | --- |
| `DecisionStatus` | `active` | The decision is the current one for its choice. Only active decisions are reused. |
| `DecisionStatus` | `rejected` | A reviewer rejected the decision. The record and its supports are kept. |
| `DecisionStatus` | `superseded` | A later revision of the same choice replaced the decision. |
| `ReviewState` | `clear` | The supports still hold. |
| `ReviewState` | `needs_review` | A support changed or was removed, or a decision it depends on is flagged. A flag does not mean the decision is false. |
| `ReviewState` | `unknown` | The state could not be established, for example while review is incomplete. The decision is treated as needing review. |
| `ReviewReason` | `source_changed` | A cited document version was replaced. Set by the document update path. |
| `ReviewReason` | `source_removed` | A cited document was deleted or purged, a cited event was redacted, or a task with cited records was deleted. |
| `ReviewReason` | `source_changed_during_recording` | A cited document changed while the decision was recorded. The result carries a warning. |
| `ReviewReason` | `dependency_review` | A decision the record depends on was flagged. Set by review propagation, which `continue_decision_review` runs. |
| `SupportKind` | `document` | A `DocumentSupport`. |
| `SupportKind` | `event` | An `EventSupport`. |
| `SupportKind` | `decision` | A `DecisionSupport`. |

### Agent result status

`AgentRunResult.status` has six values. The built-in agent sets the first value that applies, in this order.

| Order | Value | Set when |
| --- | --- | --- |
| 1 | `recording_failed` | A task write did not complete. |
| 2 | `budget_exhausted` | The run used its tool or time budget. |
| 3 | `partial_retrieval` | A retrieval call failed. |
| 4 | `partial` | An invalid citation exists, or no structured answer was produced. |
| 5 | `insufficient_evidence` | The answer's support status is `insufficient_evidence`. |

## Exceptions

The history, decision, and retention writes do not raise for a refused write. They return the error codes above. The `_WriteRefusedError`, `_DecisionRefusedError`, and `_RetentionRefusedError` classes are internal, so they are not listed here.

The catalog lists the public exception classes. A class is public when its module name does not start with an underscore. `CutoverJobLeaseError` in `agrag/ingestion/_cutover.py` is not in the catalog for that reason. The base classes with no raise site in `agrag` are marked as bases. Catch a base class to handle every subclass.

### Graph store

| Class | Base | Raised when |
| --- | --- | --- |
| `GraphStoreError` | `Exception` | The base class. A query or transaction failed in the backend. |
| `GraphStoreMissingExtraError` | `GraphStoreError` | The Neo4j or FalkorDB client package is not installed. |
| `GraphStoreWriteConflictError` | `GraphStoreError` | A write reaches a row that an in-flight job owns, and the write cannot defer it. The transaction rolls back. |
| `GraphStoreConstraintViolationError` | `GraphStoreError` | The backend reports a uniqueness violation. History writes retry it up to three times. |
| `GraphStoreAliasConflictError` | `GraphStoreConstraintViolationError` | A merge key alias is already owned by another entity. Raised by the entity merge step. Attribute: `conflicts`. |

### Embeddings and vector stores

| Class | Base | Raised when |
| --- | --- | --- |
| `EmbeddingError` | `Exception` | The base class for embedding errors. No raise site in `agrag` uses it directly. |
| `EmbeddingMissingExtraError` | `EmbeddingError` | The local sentence-transformers embedder or the reranker needs an extra that is not installed. Attribute: `extra`. |
| `EmbeddingDimensionMismatchError` | `EmbeddingError` | The embedder produces a dimension that differs from the stored index. Attributes: `expected`, `actual`. |
| `VectorStoreError` | `Exception` | An external vector index operation failed. |
| `VectorStoreMissingExtraError` | `VectorStoreError` | The client for the selected vector store is not installed. Attribute: `extra`. |
| `CollectionMismatchError` | `VectorStoreError` | An existing collection has incompatible dimensions, distance, or metadata. |
| `VectorPlacementError` | `VectorStoreError` | The requested vector placement differs from the placement recorded in the graph. |

### Ingestion and loaders

| Class | Base | Raised when |
| --- | --- | --- |
| `IngestionError` | `Exception` | The base class for ingestion errors. Ingestion code catches it to skip a source. No raise site uses it directly. |
| `UnsupportedFormatError` | `IngestionError` | No registered loader reads the file extension. Attribute: `extension`. |
| `MissingExtraError` | `UnsupportedFormatError` | A loader exists for the format, but its extra is not installed. An error policy treats it like an unsupported format. Attributes: `extension`, `extra`. |
| `DecodeError` | `IngestionError` | The source bytes do not decode under the forced encoding, or detection fails and the fallback is unavailable. |
| `MalformedRecordError` | `IngestionError` | A record in a record-family source, such as a chat export or a table, does not parse. |
