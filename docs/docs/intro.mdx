# Agentic GraphRAG

`agrag` is a graph-based retrieval-augmented generation library with agentic
reasoning. It builds a knowledge graph from corpus text and answers questions
with multi-strategy retrieval and LLM reasoning.

## Installation

```bash
uv pip install agentic-graphrag
```

```python
import agrag

print(agrag.__version__)
```
